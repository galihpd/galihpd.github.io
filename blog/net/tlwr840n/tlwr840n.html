TPLink TL-WR840N CVE-2018-11714 Proof Of Concept Using Bash Shell

Rewritten By Galih Prakoso November 23, 2022 · Network Security

TPLINK TL-WR840N

This is a Proof of Concept (PoC) based on CVE-2018-11714, which was originally discovered by Touhid Shaikh. The issue is caused by broken session handling within the firmware's /cgi/ directory. This vulnerability allows an unauthenticated attacker to download the router configuration file and subsequently gain access to the admin configuration panel.

This security issue affects firmware version 0.9.1 3.16 v0001.0 Build 170608 Rel.58696n, and it remains unpatched in newer versions (such as 0.9.1 4.16 v0001.0 Build 180614 Rel.40494n). Please contact your vendor to report this issue so they can release a patched firmware version as soon as possible.

CVE Source

For full details and technical specifications on the vulnerability, refer to the official NVD record:
https://nvd.nist.gov/vuln/detail/CVE-2018-11714

Software Requirements

To run the exploit script locally, ensure you have the required utilities installed on your system:

sudo apt-get install curl dd openssl net-tools -y

How To Use

To execute this code, simply make the setup script executable and run it in your terminal:

./setup

How To Decrypt

To decrypt the downloaded configuration file easily, you can use a free Windows utility provided by NirSoft called RouterPassView. If you are not running a Windows operating system, you can use a virtual machine (e.g., VirtualBox, VMware running ReactOS/Windows) to run RouterPassView.

Alternatively, if you prefer utilizing a pure Unix/Linux environment, I have included an automated decryption routine directly inside the script using dd and openssl.

If the decryption is successful, you can open the decrypted configuration file in any text editor (such as nano, Vim, or VS Code) and search for the AdminPwd key to extract the admin username and password. For example, if you find a string like the one below, the password is iloveyou123:

AdminPwd^C^@Eiloveyou123
